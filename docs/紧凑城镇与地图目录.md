# 紧凑城镇与地图目录

2026-11-20。按用户最新布局，底栏「地图」打开双栏目录。左边为大地图区域，右边为该区域的小地图。挂机图、村落和城镇并列显示，点目标后直接发起旅行。当前位置可见，点选同一张图不换场景。

当前开发区域为比奇省，含林间战场、银杏山谷、边界村和比奇城。区域目录允许只有挂机地图的分组。此轮沿用已开放的个人挂机图和战斗经济。银杏山谷、边界村、比奇城分别使用独立的 17×17 菱形地图，地格与野外一致，城镇不刷怪。三处分别安置 6、6、7 位 NPC，名称及原坐标来源写在玩法工作簿及生成证据。本作紧凑图重新布置 NPC，站立外观复用当前项目的通用形象。

旅行走现有服务端准备、资源预载、提交和新基线确认。客户端发送从目录选择的目标 ID，服务端选入场点，NPC 格是静态阻挡。城镇之间保留不同世界，返回林间战场沿用原角色的个人现场。旧角色的比奇省大图绑定和回执继续按原地图核验，从旧绑定施放瞬息移动时进入对应的新城镇。大图仅作旧绑定来源。

固定目录及两个可滚动列表保存在 `Game.scene`。地点、NPC、当地位置和安全区配置来自唯一玩法工作簿，客户端与服务端 JSON 均由导出工具生成。
