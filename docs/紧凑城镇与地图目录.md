# 紧凑城镇与地图目录

2026-11-20。按用户最新布局，底栏「地图」打开双栏目录。左边为大地图区域，右边为该区域的小地图。挂机图、村落和城镇并列显示，点目标后直接发起旅行。当前位置可见，点选同一张图不换场景。

比奇省含林间战场、银杏山谷、边界村和比奇城。区域目录允许只有挂机地图的分组。银杏山谷、边界村、比奇城分别使用独立的 17×17 菱形地图，地格与野外一致，城镇不刷怪。规则 30 的三座城镇分别安置 6、6、9 位 NPC，名称及原坐标来源写在玩法工作簿及生成证据。紧凑图重新布置 NPC，站姿使用原版 NPC 外观。 [原版外观接入](城镇NPC原版外观接入.md)

旅行走现有服务端准备、资源预载、提交和新基线确认。客户端发送从目录选择的目标 ID，服务端选入场点，NPC 格是静态阻挡。城镇之间保留不同世界，返回林间战场沿用原角色的个人现场。旧角色的比奇省大图绑定和回执继续按原地图核验，从旧绑定施放瞬息移动时进入对应的新城镇。大图仅作旧绑定来源。

规则 30 的城镇点击寻路在同样短的候选中优先沿起脚格到目标格的方向。无遮挡时沿八个方向直达，绕障仍遵守 NPC 格、共享占位和斜角约束。NPC 当前站姿的可见像素触发交互，图像内的透明地面和根节点空白区域仍能点地寻路。 [城镇最短路](../server/internal/townnav/nav.go) · [触屏路线验收](../tools/client/ground_navigation_browser.cjs)

紧凑城镇精确点地时，等长路线按沿途各格到点击直线的偏差之和选择。从三座城镇的出生格 `(8,13)` 点击仓库旁的 `(6,8)`，旧路线会先走到 `x=5` 再折回。修复后的路线仍走六步，依次经过 `(8,12)`、`(7,11)`、`(7,10)`、`(7,9)`、`(7,8)`、`(6,8)`。 [三城碰撞测试](../server/internal/townnav/compact_route_test.go)

银杏山谷、边界村和比奇城均以真实触屏点击此位置。旧版与新版都准确上报 `(6,8)`，新版服务端落格及客户端脚点插值都不再越过目标列。 [旧版轨迹](../.work/server-directory-browser-2753164880/town-display-route.json) · [修复轨迹](../.work/server-directory-browser-2809723952/town-display-route.json)

在银杏山谷、边界村和比奇城实测共 48 次触屏点地、96 步服务端落格。每座城镇分别核对八方向两步出发和两步返回，真实目标均到达并逐步匹配原点击方向。 [四服与三城联机记录](../.work/server-directory-browser-618994575/server-directory-browser-report.json)

加入 NPC 像素命中后，在最终 Creator 构建上逐城复测八方向、混合斜率、透明空地及绕障。共 57 条触屏路线、132 步服务端落格。三处透明点均准确发送地格并在六步内抵达，三名 NPC 的可见部位均可打开原商店。 [真实触屏逐步记录](../.work/server-directory-browser-1110528435/server-directory-browser-report.json)

城镇内点到自己角色身体覆盖的空地时，由地图处理轻触。点击按刚按下时看到的地格提交，镜头继续移动也不会改掉目标。若原目标格被其他角色或宠物占住，可沿已有策略寻找邻格。一旦发现原格腾空，服务端立即按原点击目标重新规划，保留本次寻路的计算预算和输入身份。 [地面触摸](../client/assets/scripts/input/MapTouchNavigator.ts) · [共享城镇重规划](../server/internal/game/town_navigation.go)

三座城镇的新版触屏验收共验证 63 条路线、138 步服务端落格，逐城核对角色身体覆盖的相邻格、八方向直走、混合斜率及 NPC 拐角绕行。 [触屏复测](../.work/server-directory-browser-4055280244/server-directory-browser-report.json)

共享城镇中，其他角色和宠物按当前显示的身体像素处理触摸，透过原图透明处仍能点地。点击可见身体保留实体选中。目标格在行进中被占时，原路线能走的部分继续走，重规划时可先走到可达邻格。占位解除后继续前往原点击格，沿用原输入代次和累计搜索预算。 [身体命中](../client/assets/scripts/app/TownTouchHit.ts) · [共享占位回归](../server/internal/game/town_navigation_test.go)

原点击格被本角色的跟随宠物占用时，角色走到可达邻格后，宠物在自己的动作间隔结束时迈向一个合法空格，角色沿同一次点击继续到达原格。让位仍检查静态墙角、NPC 和共享占位。其他角色占格时继续等待原格腾空。双连接联机回归核对了自己的宠物单步让位、原点击格到达，以及另一角色和宠物的位置保持。 [宠物让位与原路线](../server/internal/game/town_navigation.go) · [双连接联机回归](../server/internal/integration/town_pet_navigation_test.go)

新版实包分开通过三座城镇的 63 条路线、138 步权威落格和比奇城双端触屏。在同服第二个角色的精灵外框内，点可见身体仍选中角色，点相邻透明处会发送正确的目标格，角色也实际走到了该格。 [三城逐步记录](../.work/server-directory-browser-3562556271/server-directory-browser-report.json) · [双端透明命中记录](../.work/server-directory-browser-2503522603/server-directory-browser-report.json)

固定目录及两个可滚动列表保存在 `Game.scene`。地点、NPC、当地位置和安全区配置来自唯一玩法工作簿，客户端与服务端 JSON 均由导出工具生成。
