# 职业宠物生命周期与召唤实施边界

状态：实施中，尚未完成召唤业务验收。承接rule15；本文件不宣布技能开放或完整三职业完成。护符包的本作Count单位及售价已再次向用户提出具体问题，未收到答案前不启用护符购买、不把MYF的DuraMax当作张数。运行参数继续只维护两本唯一Excel，以下数值是来源定位记录，不是第二份运行配置。

## 身份与范围

稳定MYF身份为技能17《召唤骷髅》、原书25，Crystal对应SummonSkeleton；技能16是困魔咒，不能混用。本阶段拟将当前道士入场免费骷髅推进为原书学习、合法材料与主动施放产生的真实职业宠物。初始赠书不自动增加召唤书。

最终策划4.20规定普通个人场景只允许一只活动职业宠物。这是本作明确例外，不能照搬来源两个怪物宠物名额。尸体不是第二只活动宠物；不能因固定宠物槽而未经说明删除仍应存在的来源尸体，也不能用两个活动宠物来规避替换和身份隔离。

MYF宠物模板等级与Crystal的PetLevel、MaxPetLevel、PetExperience分开。现有变异骷髅模板的Level15不等于训练15级。Crystal HumanObject创建骷髅时设置PetLevel=magic.Level、MaxPetLevel=4+magic.Level，这是已读源码候选；MYF变异骷髅与Settings.SkeletonName的对应仍须登记为跨来源候选，不冒称找到原Settings配置或目标1.80完整认证。

## 受理、召回和材料

HumanObject.SummonSkeleton先检查当前地图NoPets，再查同名、存活且有Node的宠物。已有同名活宠时只排500ms Recall并返回，不消耗护符；通用施法路径的MP及动作/CD仍按来源发生。新生召唤才检查并消费一个Amulet Count。不能把技能17永久写成“任何施放都扣一张”，也不能让客户端无符时一律拒绝合法召回。

本作新材料施法沿既有owner原子扣除、永久typed回执和一次临时生效链路。手动及自动的永久操作身份保持，未知提交沿原job、原指纹和原材料实例对账；重放回执不能重造宠物。材料永久扣除成功后才安排临时事件。角色、授权、Life或原owner已失效时不补发临时效果，不从永久回执在冷入场重建宠物。

地图NoPets须来自唯一配置的显式政策，不能用NoTeleport、安全区、客户端按钮或无怪物推定。受理前资源校验与来源先扣MP的失败路径差异按本作既有施放管线登记，不能悄悄沿用源失败扣耗。

## 500ms事件及World驻留

HumanObject把主人、新宠物与受理时Front放入原地图ActionList，500ms后由Map.CompleteMagic处理。原主人Node/Info失效或主人死亡时不出生；这不沿用21允许同Life尸体完成旧动作的特例。

原地图capturedFront通过来源静态ValidPoint时，宠物出生在原地图；否则才尝试到期主人当前地图和当前脚点。不得为方便把所有付费延迟事件都改成跟随主人到期地图，也不得因原World已休眠而丢掉已释放地图事件。不能额外以动态空格筛选替代来源出生资格。Spawned会覆盖先前ActionTime，新生首次可行动截止须按实际Spawn链核定，不能只取创建时的+1000ms。

MonsterObject.Spawned最终把首次ActionTime设为实际出生时刻+2000ms。PetRecall只在异图时尝试Teleport：先主人Back（按到期朝向反向一格），失败再退主人脚点；同图不擅自增加拉回身边的位移。NoPets读取到期主人地图，为true时按来源留在原图，不抹掉健康宠物。

因此宠物执行驻留与主人当前World分别表示：永久owner仍唯一，活动宠物指针仍唯一，PetWorld明确它当前属于哪个保留World。旧World解析不到幽灵玩家，新World也不能把异图宠物当居民。普通健康旅行继续移交同一已有宠物；新生、召回与NoPets按各自来源处理。当前手动旅行通常收束事件后切图，不构成删除异图出生分支的依据。

稳定实体handle不能代替生命身份。跨nil、死亡和替换分配的宠物Life必须单调，溢出拒绝；迟到攻击、材料回调、训练经验和表现不得作用于新宠。死亡后的尸体驻留、到期退役与新生名额分开记录；临时位置、HP、训练现场及召唤队列不写入永久角色快照。

源DeadDelay由Crystal AI分支选择，默认分支为180000ms；MYF Race100不证明其对应Crystal AI23或原服尸体期限。尸体TTL和有界容器的最终候选须另落唯一Excel，未配置时不填代码默认。Despawn广播移除、清原ActionList及Node；这些步骤不能用简单把HP回满替代。

## 训练与属性

MonsterObject.Die经合法经验归属调用PlayerObject.GainExp；后者对与主人同图、DataRange内且存活的宠物发PetExp(amount)，并不要求宠物是最后一击。来源骷髅训练经验乘3，门槛为(PetLevel+1)×20000，每次调用只升一级，保留超额，不改成while连升。达到MaxPetLevel不再增加训练经验。

原复制片段未包含Globals.DataRange定义；后续在本机CrystalLatest找到九份与现有副本逐字一致的核心文件，Settings也匹配历史登记摘要，独立Globals副本明确DataRange16。对应证据见《职业宠物补充来源契约.json》，选入运行仍须唯一Excel候选。CrystalLocal是另一版本，召回及NoPets分支不同，不混用。默认名不证明原服实际配置，来源账号、部署配置和运行数据库不作为这次研发输入。

RefreshAll按PetLevel增加HP及AC/MAC双端、DC双端；移动/攻击间隔的减少却按MaxPetLevel计算并保留下限。刷新属性不会自动SetHP到满值，不能借升级回血。系数及逐阶上限须作为唯一Excel字段，不能在game代码中散落新数值默认。

本作永久角色EXP及奖励沿已有kill队列确认。训练资格与原宠物身份须冻结并只消费一次；不能在异步回调里直接给当前r.Pet发旧经验。若训练在永久EXP确认后推进，与源同步GainExp及同批后缀属性时序的差异须单独登记并验收。旧图击杀的信用与当前主人/宠物所在World不是同一概念，不能把“宠物必须在怪物死亡地图”当成源码资格。
