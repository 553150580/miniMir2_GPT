# M4 挖矿隔离验收

两层独享矿区通过现有地图列表和切图确认进入。第一层、第二层的候选等级门槛分别为 20、36 级。开采使用角色背包中选择的单把锄头，已有城镇杂货商在隔离配置中出售两层试用工具。战斗装备和怪物槽留在原普通地图，回去后继续使用原设置。 [策划 §4.25](../最终策划案.md#425-挖矿图纸打造与修理) · [矿区入口](../server/internal/game/mining_travel.go)

每 3 秒完成一次判定。成功率、两层矿种权重和纯度档来自唯一玩法工作簿。成功产出的矿石单块入包，纯度随原实例保存；是否绑定取决于成功时原角色的特权卡状态。成功和失败都扣一轮锄头耐久，耗尽移除原工具，背包无空位时在判定前停采。 [挖矿回执](../server/internal/persistence/mining_attempt.go) · [来源投影](../tools/resources/prepare_mining.py)

在线开采使用玩家在线时长。掉线后的每轮开采只有在具备完整 3 秒托管余额时才执行，耐久、实际扣时与矿石结果原子提交。余额不足一轮会暂停并保留余量。健康接回恢复原矿区、工具和已确认结果。关闭服务后，未提交的临时周期不补跑。提交结果不明时使用原事件编号重查。 [托管运行](../server/internal/game/mining_tick.go)

## 独立复验

```powershell
./tools/dev.ps1 python3 tools/server/run_integration_batches.py --group mining
```

Creator 3.8.8 的隔离网页包在 390×844 触屏视口实测选服、选矿层、开停挖、查看原矿石纯度和锄头耐久，再返回普通图。三轮判定得到一块纯度 76 的绑定铁矿，浏览器和持久账本记录的原锄头耐久均从 12 降至 9。 [触屏脚本](../tools/client/verify_mining_browser.cjs) · [图形结果](../.work/m4-mining-build/browser-mining-e5691a985e3d45cfb082be06778113fc/result.json)
