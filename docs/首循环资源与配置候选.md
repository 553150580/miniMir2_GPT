# 首循环资源与配置候选

本批次用于用户授权的首循环开发，不表示已经恢复并验收官方1.80。唯一玩法Excel新增51条candidate记录，原有记录不变。正式发布仍由缺口和验收门禁阻断。

## 资源契约

资源只保存一份：`client/assets/resources/development/`。Creator可从`development/manifest`加载JSON，从帧PNG去扩展名后追加`/spriteFrame`加载图片。`manifest.json`记录4种profile、1593张原帧、WIL/WIX完整摘要、转换器和格式证据。

`profiles[id].layers[].actions[action].directions[0..7].frames`引用根`frames`的键。动作有standing、walking、attack、struck、die。方向按上、右上、右、右下、下、左下、左、左上排列。原图尺寸和offset保留，不裁边、不居中、不缩放。原格左上为draw origin，图像左上为origin加`offset_x/offset_y`。人物Weapon在0/5/6/7方向先于Hum绘制，其余方向在Hum、Hair后绘制，详见`layer_order_by_direction`。

原WIL带填充帧，不能直接使用Crystal压紧后的帧号。玩家动作原相对起点为0/64/200/472/536，方向步幅8；怪物为0/80/160/240/260，方向步幅10/10/10/2/10。动作数量和时长参考Crystal，原索引和padding结合源像素逐方向核对，仍保留跨来源candidate标记。

`maps/first-map.json`来自原0.map的(128,128)局部。逻辑16×16，原格48×32，背景PNG为768×512，三层引用与原字节偏移保留。三图层0x8000位生成17个阻挡格，239个可走格连通；出生(8,8)、宠物(8,7)与8个怪物槽均由连通格确定。它们是开发选择，不沿用旧出生坐标。

## 配置契约

`config/development/first-loop.json`由当前唯一Excel导出。只接受`development_only=true`、`source_status=candidate`、`runtime_ready=false`的显式开发profile。`gameplay.json`仅提供客户端名称、物品类型/装备槽、职业形象及逐级经验，不含服务端攻击、防御、掉落权重或开发回收奖励。

| 内容 | 来源与实际取值 |
| --- | --- |
| 稻草人 | MYF Monster.csv第13行，HP15、攻击1..2、防御0、经验15、攻击2500ms、移动1500ms |
| 骷髅宠物 | 同文件第381行变异骷髅，HP60、攻击10..20、防御10、攻击/移动1000ms；只注入道士开发夹具，召唤资格、技能和耗材尚未验收 |
| 三职业1级基值 | Crystal BaseStats.Calculate，战士HP/MP18/14、法师15/17、道士16/13；空手攻击0..0、防御0；HumanObject攻击1386ms、移动600ms |

仅开发物理管线许可区间取样减固定防御，最少伤害可以为0；完整幸运、命中、技能、元素、Buff与目标1.80行为尚未验收。正式`game_recycle_values.gold_distribution`继续为null。主动复活不收费、不掉经验、不掉装备，健康重连不回血，这些仅为闭环测试条件。

来源Idx193原名“布衣(男)”只保留在来源备注，目标名称统一为“布衣”。按最终策划4.2/4.20取消性别穿戴门槛，三职业均可穿同itemID；男女分层PNG是当前外观候选，女法师衣服映射与三职业最终外观仍待资源验收，不能据来源男装名称排除法师。

## 重现与检查

```sh
./tools/dev python3 tools/resources/build_development_assets.py --check
./tools/dev python3 tools/resources/prepare_first_loop.py --check
./tools/dev python3 tools/config/export_configs.py --check
./tools/dev python3 -m unittest discover -s tools/config -p 'test_*.py'
```

改动开发候选时先编辑唯一Excel，再运行`prepare_first_loop.py`导出共享夹具和客户端公开映射。`--extract`只用于尚未初始化开发表的首次来源提取；现有开发表会拒绝重新覆盖。艺术批次需要重生时运行资源工具的不带`--check`命令，然后重新审视来源锁和验收记录。原始WIL/WIX/map/CSV/源码始终只读。
