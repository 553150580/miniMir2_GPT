# M4 矿战现金流实测

两层矿区各取无卡、仅特权卡、仅托管卡和双卡各 1 个战士。独立 MongoDB 和真实账号服、游戏 WebSocket 跑完整角色路径。首次附着前设置矿层准入等级，角色初始金币为零，只准备原购卡款和独立买家的交易本金。角色通过正常协议穿建角木剑和布衣、付费开卡、领取当日托管时长。锁定备用赠品，筹资只计实际击杀直接金币和新掉落的普通、精良装备回收。 [真实联机用例](../server/internal/integration/mining_battle_economy_test.go)

每个角色先在杂货商验证金币不足，随后入矿验证无锄停采。回林间战场以四怪设置赚取首把锄头的整价，回城确认扣款。原两层试用锄头按配置分别实付 50 和 80 金币，耐久分别为 12 和 16 个存储单位。进入矿区时保存原普通图与怪槽，使用工作簿的 3 秒、30% 出矿与两层矿种和纯度权重。首轮在线确认后断开，离线开采到原锄头耗尽再签票重连。第一层对应 33 秒离线扣时，第二层对应 45 秒。 [唯一玩法来源的隔离投影](../tools/resources/prepare_mining.py)

无特权分组让合格的新采矿直接回收。持特权分组保留原矿，以其中符合条件的原实例做单块 NPC 出售和市场交易。返回普通图后再次实际击杀。所有矿区流水均核对原审计、发生时刻、工具版本、判定前后耐久、出矿绑定和托管余额。采矿期间普通击杀、经验和战斗装备耐久的增量均为零。托管卡的加成逐杀与直接金币和经验对账，矿石回收只按配置单价逐块取整。角色的四钱包按前后两段普通击杀与回收、购锄、实矿回收和出售逐笔复算。 [逐轮账本校验](../server/internal/integration/mining_battle_ledger_test.go)

市场闭环使用第一层持特权矿工实采的一块纯度 1 非绑定铜矿。核对原竞购截止后在隔离库缩短等待，由正常排程转直购，再让原买家付费和卖家取款。买家支付 2.9 非绑定元宝，卖家实领 2.7，市场扣除 0.2。原矿编号、纯度和绑定随成交保留，买入与取款各重放一次。 [成交用例](../server/internal/integration/mining_battle_market_test.go)
