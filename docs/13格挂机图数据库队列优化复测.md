# 13×13 个人挂机图数据库队列优化复测

2026-11-22 在同一 Windows 开发机复测规则 26。上轮边登录边挂机的结果见[前次压测报告](13格挂机图5000角色压测.md)。当时实际进入 4914 人，共有 547 次新入场被游戏服以 `server busy` 拒绝。另一次先入场后挂机的 5000 人保压测得收益确认 P99 16.05 秒。

## 改动

- 入场票据查询和角色接管各有 128 个排队位，共用 6 个入场执行协程。队列过载通过入场协议返回明确错误。
- 结算任务有独立的有界 FIFO，每个房间最多一笔待确认任务，容量随房间准入总额计算。普通资产业务和收益共享 24 个执行协程，两队列都有任务时交替处理。遇满任务延迟再次提交并保留原来源身份。
- 同一账号守卫组的事务在进程内串行，减少争写同一守卫文档。业务连接池上限为 32，续租仍走独立控制连接池。MongoDB 围栏、3 秒事务截止和多数写确认保持原语义。
- 单笔收益的角色 CAS、永久回执与审计在同一事务内通过一次跨集合写命令提交。版本未匹配或后续写出错会回滚该笔事务。未知结果继续沿原来源确认。

## 复测条件

使用与上轮混合负载相同的隔离构建配额，即 5500 条 WebSocket 和每个角色 worker 768 个房间。独立 MongoDB 8.0.34 使用同样的 256 MiB WiredTiger 缓存与 128 MiB oplog。压测客户端用 16 路并行领取单次票、连接游戏 WebSocket、确认首基线，随后立即开启真实自动战斗。5000 个合成账号各一名 45 级战士，每图 8 只原配置怪物。分 100、1000、2500、5000 人升压，最终观察 180 秒。

入场统计从领票到自动战斗回显成功。收益计时从游戏服尝试提交结算任务到收到成功回执，包含排队和原任务重试。MongoDB `commitTransaction` 单独计时。真实 MongoDB 回归验证了写入冲突时角色、回执与审计的原子回滚，以及重复来源、旧会话和旧所有者语义。独立 WebSocket 回归覆盖了入场错误、挂机和健康重连。

## 复测结果

两次混合升压使用相同的接入并行度。首次成功率按每个角色第一次完整入场计算，服务器忙的次数包含对同一角色的多次尝试。

| 入场指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 首次成功 | 4688／5000（93.76%） | 5000／5000（100%） |
| 重试后的最终成功 | 4914／5000（98.28%） | 5000／5000（100%） |
| 最后 2500 个角色加入耗时 | 84.95 秒 | 6.61 秒 |
| 入场失败次数 | 547 | 0 |

最后一档 2500 个新角色的入场确认 P99 为 87.88 毫秒，最慢 135.33 毫秒。5000 个角色在 180 秒保压中持续在线、存活并自动战斗，客户端观察到 5000 个独立场景，与 8 个 worker 的房间总数相符。每个角色都有攻击和收益确认，坐标抽查无变化。共收到 223,265 笔收益确认，约 1240 笔／秒。全轮没有在场掉线、客户端协议错误、节点续租告警或 MongoDB 写确认超时。

| 满载确认环节 | P50 | P95 | P99 | 最大值 |
| --- | ---: | ---: | ---: | ---: |
| 游戏服收益结算（含排队） | 40.43 ms | 118.62 ms | 200.19 ms | 335.39 ms |
| MongoDB 应用事务 | 10.15 ms | 18.08 ms | 25.67 ms | 103.75 ms |
| MongoDB `commitTransaction` | 4.60 ms | 7.18 ms | 12.87 ms | 80.64 ms |

与前次先接入再开启挂机的 5000 人保压相比，收益结算 P99 从 16.05 秒降至 200.19 毫秒，吞吐从约 718 升至 1240 笔／秒。新一轮满载结算队列的采样峰值为 319／6144，全轮四条队列均未触满。100 人升压热身期收到过 17 个带暂态事务标签的提交命令错误，驱动重试后应用事务成功。5000 人升压和保压阶段写关注错误、写确认超时、提交结果未知和应用事务最终失败均为 0。

5000 人保压期间，游戏服平均占用 11.38 个逻辑核，采样峰值常驻内存 590 MiB。MongoDB 平均占用 6.58 个逻辑核，采样峰值常驻内存 516 MiB。与上轮满员保压相比，游戏服和 MongoDB 的 CPU 占用随实际结算吞吐上升。Go GC 共 1430 轮，暂停累计 927 毫秒，单次暂停 P99 位于 1.31–1.57 毫秒区间。

本机在线定点挂机混合升压通过本轮验收，收益结算 P99 低于架构方案的 500 毫秒初始目标。测量覆盖同机 MongoDB 单成员副本集和 180 秒满载窗口。原试玩继续使用其原有的启动实例和配额，隔离压测的节点和数据库已清理。
