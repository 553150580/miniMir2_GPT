# 权威位移与导航观察实施边界

本阶段是完整三职业技能的共用依赖，不把抗拒火环8、野蛮冲撞27或瞬息移动21计作已开放或已还原。位移距离随阶增长、绑定地图/绑定点、跨图、TemporalFlux及护符单位和报价分别保留原待定/待核验状态；不以本阶段代替完整P0。

## 权威路径和水位

`EntityState`追加21号`movement_revision`和22号`movement_kind`。运动水位为uint64，按scene、handle、life隔离；普通行走成功也递增，不复用状态快照序号。kind为技术枚举：0初始、1普通走、2被推、3冲撞、4传送、5冲撞失败。服务端不得在溢出后回绕并继续提交坐标，应隔离原现场。

新增S2C30013 `EntityDisplacement`，携带原scene/实体life、水位、origin、按处理顺序的真实path、身体面朝、推进方向、观察用每格时长、原技能/施法身份和攻击/施法身体序号水位。被推/冲撞的每个path点为成功一格后的坐标；传送恰一个落点，邻格或原地也显式传送；冲撞失败允许空path，不虚构成功格或2秒业务锁。客户端没有通用强制移动请求。

源Pushed/ShoulderDash在同步循环内逐格发包。本作可将同一次调用已处理的成功前缀合并成一条路径，先发事件再发同水位最终基线；不得仅留末点、补未成功格或把循环拆成显示驱动的业务延迟。同一施法中对同一实体的再次推挤分别推进水位，并保留各调用的真实顺序。

Ready前照常推进世界，但不补发旧瞬时事件；初始/健康重入仅由基线采用当前落点。客户端基线先到、事件丢失时校准到权威位置并抬高水位，迟到旧事件不补播；事件先到时，同水位基线更新HP、状态和文字，不重启轨迹。新life、离场、销毁隔离旧事件；普通后续步从已确认路径末端接入，有界追赶，不外推未知格。

身体面朝与运动向量分别处理。被推用已有Walking倒序隔帧，冲撞用Running两组三帧；本作以观察用每格时长平滑显示，源全局100毫秒tick的初相位和卡帧墙钟不声称完全相同。Dash首相按本人/旁观对象的当前动作和待播队列决定，不每批固定从L起。旧身体动作与hold按事件序号水位让位，新于水位的有效待播动作保留；已释放的投射物、命中、治疗和永久结算不能随身体抢占取消。

`EnterLineResult.player_handle=9`明确当前附着角色的实体句柄。本人/旁观者的Dash首相、通用传送离场特效及镜头归属按此身份判断，不把所有kind1或固定句柄1猜成本人。当前仍是个人场景唯一玩家；该字段不代表公共多玩家、其它玩家姓名与完整共享场景已实现。

## Pushed来源子集

来源HumanObject.Pushed:2649–2724、MonsterObject.Pushed:1035–1093。仅检查目的格Walk与动态Blocking，不复用普通走禁止切角的邻格规则，不递归推开挡路者。Monster/Pet须读取当前定义的`can_push`，不能由客户端授予。每个成功格后朝向反向；保留已发生的成功前缀。

遇地形无效/越界是early return，跳过后置时钟；遇动态占格是break，仍正常收尾。正常收尾Human动作锁由唯一Excel的`player_push_action_ms`决定；Monster动作与移动锁分别按独立的每格配置乘成功步数。零步动态阻挡也保留源收尾区别，免疫/旧引用/invalid early return不借此改时钟。AttackTime、共享法术及单技CD保持。

Human来源没有独立MoveTime；本项目普通walk将同一动作锁同时映射到NextMove和ActionReadyAt，因此Human正常收尾同步二者至新动作截止。怪物仍是两个独立时钟，不能以max保留旧值替代源赋值。仅实际成功路径取消旧纯观察身体姿态；零步不能伪造Pushed动作。

当前runtime尚无Concentration、持续地面Spell和安全区绑定语义，本阶段不写假空hook冒充这些源分支已实现；对应技能与场景接入时须补齐。运行碰撞来自唯一Excel的四件场边小物，源17阻挡继续仅作来源证据。

## 导航确认与复活

`SceneBaselineChunk.navigation_state=8`携带最后地面目标的input_sequence、destination、目标revision和状态：0无、1进行中、2已到达、3玩家主动方向接管、4显式取消。目标revision为uint64，只在新地面目标被接受时推进；到达、接管、取消、同图复活和健康重入不重置。健康join的输入序号仍按原流程从0开始，客户端发新目标时记录已见目标revision作为下界；只接受更高revision且匹配当前输入的目标，再按同revision确认到达。如此同坐标新目标及重入后复用input_sequence不会被旧回执结束。分块组装、初始和健康重入保留该状态，恢复目标不得重新发送旧意图；身份溢出受控隔离，不回绕。

正常Ready连接显式退出/换角使用`MoveIntent.cancel_navigation=6`。服务端按原scene、binding和输入水位核验后清地面目标及摇杆，保留原目标身份并置4；无地面目标保持0。回同Request头的单完整场景基线作为确认，不借用假方向或同地面点。客户端等待本次确认后才关闭连接；等待期间屏蔽新本地移动，拒绝或超时不能冒称已取消。普通release、失焦、后台、健康断线不发送cancel。非Ready/已断线的本地退出不声称已确认远端取消，网络故障下的退出意图交付仍须后续独立验收。

强制路径中间点不作导航到达证明，Pushed不清Destination；服务端在自身推进中确认完成，后续从新脚点规划。面板、聊天、实体点击、失焦、后台及尺寸变化仍只释放摇杆。按用户既有约定，同图普通死亡期间停走，复活后保留active目标及原输入身份，从新脚点继续；修正旧复活清路实现，死亡费用、复活位置与HP/CD业务另按既有规则。主动方向接管或退出游戏才结束相应导航，新世界初始化仍不从永久数据恢复临时路径。

本阶段仅当前单地图。真实跨图须给目标增加地图身份及挂起/恢复语义、健康地图资源加载和现场移交，不把同xy强套到新图，也不把同Game场景名视为已完成地图切换。
