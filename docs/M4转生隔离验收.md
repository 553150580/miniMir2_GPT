# M4 首转隔离验收

角色达到当前等级上限后，可在角色成长面板查看费用与成长结果。首次转生从 50 级开始，最多开放到 51 级。每次转生把上限提高一级，待用经验按原曲线释放。满池可以正常升到新等级，部分经验保存在新上限下的当前等级经验。装备、已完成成长和封存的历史经验继续保留。 [策划 §4.4 与 §5.1](../最终策划案.md) · [领域计算](../server/internal/domain/rebirth.go)

隔离样本在林地守卫的原胜利附件中加入 1 份转生凭证和 3 份绑定材料，两类附件即使角色有特权也固定绑定。首转消费 1 份原凭证、2 份绑定材料和 1000 金币，优先扣绑定金币。原场次、角色、原凭证编号和道具版本进入报价核验，费用、成长、回执与审计同一事务提交。重连重发已成交的原操作时返回原回执，旧会话未成交的报价失效。 [隔离装配](../tools/resources/testdata/rebirth-isolated.json) · [凭证与扣料](../server/internal/persistence/rebirth_plan.go) · [原报价与成交](../server/internal/persistence/rebirth_quote.go)
