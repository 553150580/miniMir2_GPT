# 首领挑战规则 28

规则 28 的开发配置开放个人首领「林地守卫」和世界首领「林地首领」。普通挂机与首领挑战使用同一套服务端格子移动、攻击和技能判定。进入挑战时，原挂机房间保留角色的永久写权限并继续推进。每个角色同一时间至多参加一个特殊挑战。 [玩法与归属规则](../最终策划案.md) · [个人场景](../server/internal/game/personal_boss.go) · [共享场景](../server/internal/game/world_boss_arena.go)

## 独享、共享与返回

本节记录规则 28 的行为。个人场健康断线与新票接回的当前行为见 [规则 30 个人首领健康重连](M3个人首领健康重连.md)。

**个人首领**由原角色所有者在 MongoDB 确认预约、规则版本、执行代次和固定战斗快照后创建独享副本。客户端加载地图并确认对应首基线后才能移动与施法。实际格战产生击杀、战败、到期或中断结果。原角色所有者沿同一场次和预约编号提交终态、成功次数与冷却，随后发回原挂机房间的当前基线。重复确认沿用原终态。个人场在健康断线或同角色新会话接管时收束为中断。新票进入原挂机房间，个人场内临时生命和冷却随该场结束。旧执行失权时，新所有者按原预约对账并中断悬置场次，之前已确认的成绩和回执继续可查。 [个人场景与入场](../server/internal/game/personal_boss.go) · [终态与返回](../server/internal/game/personal_boss_combat.go) · [预约、结算和故障对账](../server/internal/persistence/personal_boss.go)

**世界首领**由运行服、模板和开场时刻决定场次编号。同场所有玩家和宠物共用服务端格子与真正在场的一个首领实体。首领移动与攻击只由承载场次的分片推进。各角色攻击汇入同一条到期顺序，排行累计实际从首领扣除的生命。入场时分片先保留可走空格，确认新基线后开放格战和同场可见。击杀或到期先公布场次结果，再返回原挂机房间。主动退出立即返回，战败结束原席位。已确认的主动离场或战败席位不能借新票继续参加该场。 [世界场次与席位](../server/internal/game/world_boss_arena.go) · [合并事件与首领行动](../server/internal/game/world_boss_combat.go)

**世界场健康重连**通过账号节点给原角色重新签票。新会话先确认原普通场景，再由服务端接回仍有效的同运行服、同一场次席位，并再次确认世界场基线。旧连接立即失权且不再占格。新连接保留角色与宠物的战斗身体、血蓝、出生代次、状态、冷却和已确认贡献，旧格被占时重新挑空格。掉线时尚未实际命中的动作不补放。进程故障、场次换代或跨节点接管的世界场恢复仍待实现，当前共享场次和排行只保留在承载它的游戏进程。 [新票接回路径](../server/internal/game/world_boss.go) · [席位暂停和恢复](../server/internal/game/world_boss_reconnect.go)

## 收益与技能边界

普通怪的经验、掉落、收益来源序号、任务和图鉴继续由原挂机角色提交。两类挑战的击杀走各自场次路径，候选首领不触发普通怪复活或收益。规则 28 已导出的两个模板均未配置正式奖励。个人场次事务在隔离测试中验证了独立配置金币按原击杀时刻特权判绑及回执重放。当前个人模板的该值为零，个人装备和材料掉落仍待接入。世界参与奖、排名奖、羽毛和勋章碎片的资格、产量及永久结算待批准的奖励表和场次事务。 [工作簿投影门禁](../tools/resources/prepare_boss.py) · [个人独立金币事务及用例](../server/internal/persistence/personal_boss_test.go) · [普通来源与挑战分流](../server/internal/game/combat.go)

挑战场内支持正常普攻、近战模式和已学且当前场次支持的无耗材法术。入场快照可带已允许参战的宠物和对应战斗属性。场内药水、技能材料、召唤和装备耐久等永久变更仍需接入原角色事务。世界场的跨角色友方施法和共享火墙的格子冲突与归属尚未接通，当前只执行已具备场次语义的动作。个人场的托管自动挑战也未开放。 [技能场景门禁](../server/internal/game/skill_cast.go) · [场内战斗与耗材边界](../server/internal/game/personal_boss_combat.go)
