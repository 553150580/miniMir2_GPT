# M4 装备洗炼隔离验收

装备详情进入洗炼，左列显示已经采纳的词条，右列显示最后一次已付费候选。选中实际石堆后，服务端报价列出金币和元宝的四钱包分账、原石扣量和装备绑定结果。打开界面时绑定资源默认关闭，两次确认后才允许选绑定石和支付绑定货币。锁槽只依据左侧已有词条，至少保留一个可抽位置。 [最终策划 §4.4、§4.7、§5.12](../最终策划案.md) · [报价合同](../shared/proto/equipment_refine.proto)

生成与覆盖会重新扣除本次材料和费用。原装备、实际投入的石或任意绑定货币导致的角色绑定，在生成时和待选一同确认。采纳只替换原词条，放弃保留原词条，两个动作都不返还已确认费用和绑定。待选持久保存，等待期间依原占用防止分解、转移、上架或其它培养，报价过期不会清理已付结果。 [持久事务](../server/internal/persistence/equipment_refine_quote.go)

普通战斗和挑战快照只使用已采纳词条。固定属性与部位强化按同一属性汇总，最后取整一次，空槽和损坏装备不产生贡献。旧无词条装备的 BSON 保持缺省。候选当前覆盖精良乌木剑的防御、最大生命与最大魔法值，以及稀有原打造项链附加的攻击、魔法攻击与道术。正式词条池、阶段基值、类型权重、重复规则和总预算仍待确认。 [属性汇总](../server/internal/devconfig/equipment_contributions.go) · [隔离配置](../tools/resources/prepare_equipment_refine.py)

## 联机与触屏验证

隔离样本在谷地南坡实际击杀和分解原精良乌木剑。分解产石保持原 5% 概率，石头继承原件绑定。测试使用预置法师等级、技能、特权和首笔绑金，并缩短战斗与装备等待。实测绑金生成后立即绑定，未读回包即断线，新票恢复原场与候选，原请求重放不再扣费。放弃后原词条和绑定保留，重新洗炼并采纳的词条随原件穿戴进入权威战斗属性。 [真实联机专项](../.work/integration-batches/0d077c0042e5442d953e7c87a7042ba9/result.json)

独立 MongoDB 验证锁一槽每次支付 200 元宝的候选规则、两钱包各部分扣款的精确分账、继续生成覆盖右侧、旧候选拒绝、事务回滚和原回执重放。分解审计失败时原装备与产石一并回滚。绑定石可存个人仓，非绑石在原市场和共享仓流转。试点只开放完好、当前幸运为零的普通击杀原剑。正式产出、破损副产物及洗炼石与祝福油组合需要继续核定。 [正式候选边界](../tools/resources/testdata/equipment-refine-isolated.json)

修正后的 Creator 3.8.8 包通过真实手机视口。连续触屏完成生成、放弃、重新生成和采纳，共有四笔唯一操作。首次实际使用绑定石和绑金并立即绑定，第二次使用非绑石和金币，两个决定动作不扣款。原始实构将 BigInt 幂运算编译为 `Math.pow`，导致首次触屏虽扣费成功，界面仍停在报价。已修复并用原实发 protobuf 报文添加回归。 [候选触屏](../.work/m4-equipment-refine-build/browser-equipment-refine-acaeffc35ed84bfb92c952484b233952/result.json)

新版 Game 在 Creator 原产物中沿用旧资源路径。发布封装给新版合包加入内容版本并保留原路径旧字节，主包只新增必要的版本映射。候选触屏实收同源 HTTP 200 的新版 Game，并核对新旧摘要。 [版本化发布工具](../tools/client/version_preview_scene_pack.py)

默认实包的手机触屏保留原装备详情，洗炼入口、请求和回执均无。独立账号节点和两台游戏节点各自提供两个运行服，浏览器对四个服逐一选服、选角、入场并取得场景就绪回执，实际收到同一份带内容版本的 Game。 [默认触屏](../.work/m4-equipment-refine-build/browser-default-03c9317c54f144efb3ce63bd5f17584b/result.json) · [默认四服](../.work/m4-equipment-refine-build/browser-server-directory-efb31e6f5cd5433fa6f90cfdd2fd35ff/result.json)

全量回归使用独立 MongoDB 8.0.34 副本集和真实 WebSocket。19 组共 120 个顶层用例全通过，覆盖原登录、选服、地图、技能、托管和交易，以及三项洗炼专项。每批独立数据库均已正常清理。 [全量联机回归](../.work/integration-batches/9e0e7b59804a4d0c8d973cb6a86b2a55/result.json)

默认规则 30 关闭洗炼。公开试玩采用原玩法目录，陪测候选和默认页面使用同一客户端源码各自构建。已付词条随物品持久保存，正式开放后的降级需要使用仍能识别新字段的版本。
