# 战斗状态与防御技能实施边界

日期：2026-10-28。状态：限定开发验收通过，运行护符入口关闭。来源审计、独立.NET公式、配置、真实Mongo/WS、Creator及本机浏览器分别记录于《战斗状态与防御技能阶段验收.json》；不以这些局部结果认证完整P0或目标1.80。14/15正向材料施放仅在隔离测试实例验证，用户的护符包单位决定仍待定。

最终策划§4.8与§7.4优先。MYF技能ID14/15/31为本项目稳定身份，Crystal69/71/43只作源码候选；原WIL只提供美术参考。数值仅维护两本唯一Excel。逐项来源、行号及摘要见`资料索引/防御技能与状态来源契约.json`。

## 来源语义

- 魔法盾：延迟后仅本人获得状态。持续时间走源GetPower(int)的binary32运算和中点取偶；减伤在AC/MAC之前，以原伤减去截断的百分比计算。正净伤削减剩余时长，不按实际剩余HP截断伤害；削至非正值后仍由下一次状态处理移除。已有盾时重施不刷新，前置MP与CD仍已支付。
- 幽灵盾与神圣战甲术：选定中心的固定7×7方形，地图边界裁剪，每个目标所在格需可走；中心本身不额外拒绝阻挡，不检查飞行线。本人及自己的宠物为友方，野怪不是友方。尸体节点尚在时也可接受手动状态。持续时间只抽一次道术，增益只由目标模板等级计算，分别增加MaxMAC/MaxAC，不增加下限。
- 同种14/15重施只替换剩余时长，可以缩短；保留原属性数值和LastTime/NextTime。玩家死亡继续保留和计时，主动复活显式迁移已生效状态；迟到施法事件仍按原life拒绝。宠物尸体可保留，消失/新召唤不迁移。施加者后续死亡不删除已经应用到其他对象的状态。
- 源ExpireTime是剩余量。新状态LastTime=实际生效时刻、NextTime=0；到期处理扣真实经过时间，再排下一次检查，不补跑历史周期。受击与刷新均不重新锚定时钟。基线展示剩余可以为0，列表是否存在才是权威有效性。

## 本作明确适配

源Human先处理Buff再执行自身动作，Monster顺序不同，Map范围回调又在对象之后；不能宣称存在统一源顺序。本作每个房间固定先处理状态，再执行已到期战斗事件，采用实际处理now，不按事件旧Due重构历史属性。原Due继续用于已有击杀/绑定业务事实。

魔法盾的延迟生效要求原施法者仍存活；死亡则丢弃临时效果，不返还已支付MP/CD。这是比来源尸体回调更严格的本作适配。14/15仍允许尸体目标，不将这一约束泛化。

健康托管持续推进状态，正常重连保留同一内存现场，不照搬来源StopGame冻结剩余时长或将Buff写入永久角色。未知永久提交期间Pending暂停world处理，不平移状态LastTime/NextTime；解除后按actualNow一次扣除包含等待期的真实经过时间，CD仍按绝对时钟。暂停处理不表示冻结剩余时长。不新增HP/MP、位置、随机数或完整临时状态故障快照。

自动施法仅统计缺少相应状态的存活友方，不主动刷新已有状态，也不自动向尸体反复耗符。手动14/15仍按来源允许尸体节点。自动策略优先级为本作开发候选。

## 护符与永久资源

来源Crystal选择已装备Amulet/Shape0、Count足够的原实例，每次扣Count；MYF护身符187为Shape5/DuraMax字段，不能直接证明包内张数。独立施法材料槽不占十个强化装备部位，普通装备接口不得写该槽，也不自动寻找其他实例替换。

护符包数量与报价已向用户询问，未确认时Excel的max_stack留空、casting_supply.enabled=false，不创建护符NPC商品。生成的0仅表示未知且入口关闭，不能作为可用零堆叠。三项技能定义及材料协议可校验，14/15需材料路径保持关闭，不能冒称玩家完整购符施法闭环已经验收。

手动材料施法携带稳定OperationContext、原装备实例/版本及scene/life，先由角色owner原子扣除，再触发一次临时施法。永久回执只保存紧凑业务身份/消耗，重放先查回执，不重复生效；进程丢失临时效果不从永久回执重建战斗。自动耗符用独立SourceSeq稳定业务身份，不推进客户端EconomicSeq。未知提交沿原操作对账，不能换料、换op或猜测回滚。

## 协议与表现

EntityState全量状态增加statuses及combat_attributes，沿现有scene/stateSequence/实体life拒绝旧基线。空状态列表清除表现，客户端不凭本地倒计时删除权威状态，不自行叠加结算属性。所有64位字段保持Long/BigInt，life=0合法。

材料施法与材料槽操作分别用40014/40015，沿40005返回永久操作结果。魔法盾仍走普通临时施法30003；选择了宠物也只能自用。

普通战斗状态面板由UIMgr管理，详情由上层PopupView管理；各自返回保留下层滚动。状态徽标、详情和条目均保存为可编辑场景/预制体，使用原生组件；无单独关闭按钮。没有来源BuffIcon时使用中文短名，不拿同号技能图标冒充。

原资源新增94帧：14/15共享定向投射与各自落地，31起手和常驻/受击状态。原像素及偏移保留，区域落地每次施法只播放一次，不按受益人数重复。常驻盾由权威状态驱动，重连恢复当前壳，不重播历史起手。既有场边小型装饰、地图和头顶几何保持。
