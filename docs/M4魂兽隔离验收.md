# M4 魂兽隔离验收

角色面板的成长入口可打开魂兽名录。名录按策划编号显示十三种魂兽及其持有星级。每种最多持有一只，当前附体只取一只。伤害、防守、特效各选一项，可免费更换。魂兽和通用碎片保存在该永久角色的收藏，职业宠物、背包和交易各沿用原流程。 [策划 §4.22](../最终策划案.md#422-魂兽系统附体收藏) · [客户端操作](../client/assets/scripts/app/GameSoulBeasts.ts)

## 掉落与结算

- 骷髅精灵个人首领在原预约固定奖励条款。对应场次获胜时，同一事务确认原场终态、发放记录和角色收藏。首次获得一星，重复时转为通用碎片，最近挑战记录显示实际到账结果。
- 祖玛教主世界首领使用原始席位资格和实际扣血门槛。符合条件的参与者均有独立机会。真实击杀后生成待领附件，满背包也可领取。领取时同一事务确认角色归属、原附件、到账和原回执。重登后继续查同一笔附件和结算。
- 升星、分解、合成显示确切碎片变更，经确认后执行。已附体的魂兽先解除再分解。服务器校验收藏修订、原请求编号、费用和余额，普通挂机收益仍使用原角色资产修订。掉线重放返回原结果。

## 已验证

- 真实 MongoDB/WebSocket 中，从空收藏连续三次实际击杀骷髅精灵，取得唯一一星与 12 片。核对附体后的最终伤害、防御、准确和免费改选暴击，以及解除后的属性。旧收藏版本、错费用和附体时分解均被拒绝。升二星扣 6、分解返 7、重新合成扣 12，最终余额 1 片。断线重放只取原升星回执。 [个人首领联机用例](../server/internal/integration/soul_beast_test.go)
- 两个实际参与者击杀同一只祖玛教主，各自取得原附件。第二名满背包可领，跨角色领取被拒，断线重放后只有一笔成功入账。 [世界首领联机用例](../server/internal/integration/soul_beast_test.go)
- 单元用例从一星逐级升至七星。两只先后附体时只有最后一只生效。到七星后拒绝继续升星，分解前后通用碎片按原表结算。 [七星用例](../server/internal/persistence/soul_beast_test.go)
- Creator 3.8.8 的实际手机 Web 包通过名录、合成、附体、换词条、升星、解除及分解触屏流程。测试角色准备 30 片，六笔实际回执逐笔与 MongoDB 对账，最终空收藏余 19 片。场景基线核对换词条后的最终伤害和攻击变化。 [触屏脚本](../tools/client/verify_soul_beast_browser.cjs) · [数据库对拍](../server/internal/integration/soul_beast_browser_test.go)
- 冻结默认实包已通过原角色成长页、两个游戏节点各两个运行服的选服入场。客户端回归 746 项通过，测试替身补齐伤害飘字依赖的颜色构造与复制。收藏修订和带符号的碎片变更在协议往返中保留 64 位精度。 [四服验收入口](../tools/server/verify_server_directory.py) · [协议验证](../tools/protocol/verify_client_pb.cjs)
- 完整真实 MongoDB/WebSocket 竞态回归覆盖二十二批、共 131 个顶层用例。所有批次通过，测试副本集全部清退。 [分批运行入口](../tools/server/run_integration_batches.py)
