# M4 翅膀祝福油隔离验收

已激活翅膀可从角色装备的翅膀详情打开原祝福油面板，并在同一界面选择武器或翅膀。切换对象保留本次的绑定授权，重新打开默认关闭。实际输入只采用报价中显示的原油堆，关闭时只准非绑定，完成两次确认后绑定油优先。翅膀一直归原角色专属，页面显示其阶数、贡献和两段累计。 [最终策划 §4.6 与 §4.24](../最终策划案.md) · [工作簿投影](../tools/resources/prepare_wing_oil.py)

翅膀和武器共享原逐级成功率、回退与 100／3000 瓶阈值。达到阈值的当瓶仍按原概率，之后每瓶最多升一级。持久层按原 `wing_id` 结算，扣原瓶、修改幸运和本段累计、保存原回执及审计在同一事务。每次操作保留原阶、外观和显隐，另一段累计保持，失败也只扣实际投入的一瓶。同一请求丢回包后按原回执重放。 [永久结算](../server/internal/persistence/weapon_oil_quote.go) · [共享界面](../client/assets/scripts/app/GameWeaponOil.ts)

## 独立复验

```powershell
./tools/dev.ps1 python3 tools/server/run_integration_batches.py --group wing-oil --timeout 360
```

真实 WebSocket 从世界首领原羽毛激活翅膀，专门预置油瓶及两段保底临界进度，以固定的隐藏掷点复现失败。用油经过两个阈值后逐瓶成功。核对掉线重放、原实例与原油堆、升阶和显隐保留幸运。角色翅膀达到 +9 后，隐藏仍提供权威的 30% 幸运一击。真实持久专项复验绑定优先、审计失败回滚、并发只扣一瓶，以及旧武器和羽毛成长事务。 [真实联机](../.work/wing-oil-natural-ws/f3f3bfa24a3540848e02124537df0bf2/result.json) · [真实持久](../.work/wing-oil-persistence/a2735fceb53a4799a2f7573dd0c1bdcb/result.json)

Creator 3.8.8 手机视口从已激活的翅膀详情进入培养。取消绑定确认后仍关闭，完成两次确认后在原界面切换木剑、再切回同一翅膀，授权仍生效。实际只对原隐藏三阶翅膀使用一瓶绑定油，幸运 +3 升到 +4，原木剑状态相同，角色幸运一击从 8.8% 更新到 10.4%。关闭重开重新显示非绑定投入。原库存、永久回执和审计逐笔对拍。 [隔离触屏](../.work/m4-wing-oil-build/browser-wing-oil-5d3d870593e94b2597a42cad3b1892bc/result.json)

默认规则 30 的公开目录、角色资产兼容方式和世界首领奖表保持原样，翅膀用油仅在隔离配置开启。正式羽毛总供给、逐阶费用、战斗外观资源和经济复算继续验收。

默认 Creator 实包的手机视口保留旧穿戴格和木剑详情。客户端严格类型检查及 742 项测试通过，两种实包均在本机项目专用 Creator 目录完成。 [默认触屏](../.work/m4-wing-oil-build/browser-default-fb144ff911f64d99948bcaf6c1bdaa0c/result.json)

上轮第二节点续租事故的本机 FTDC 时序显示，当时的磁盘同步停顿与 MongoDB 多数写确认延迟一致。确认阶段的事务提交曾等待 2.0～2.7 秒，节点最终越过已确认租约的安全截止。引起停顿的具体进程或设备因素仍待归因。 [事故取证](../.work/m4-wing-oil-preview/mongo-lease-incident.md)

最终同源验收覆盖 17 组、115 项真实 MongoDB／WebSocket 联机。初跑的库存索引迁移因 D 盘低于 MongoDB 的 500 MiB 阈值中止，道士成长子例出现读取超时。空间恢复后两组用相同的 662 个 Go 和运行配置输入串行复跑，29 个顶层用例全部通过。保留初跑和复跑的原证据，两个批次共 19 组临时数据库均已清理。 [初跑报告](../.work/integration-batches/f011cbf2a29e4f5b8d19fe7f9b4ae771/result.json) · [单进程复跑](../.work/integration-batches/64706902ebaf42feba135c4e128d4020/result.json)
