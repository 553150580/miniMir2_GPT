# M4 激励视频隔离验收

激励视频位于托管面板。观看前显示单次奖励和账号今日剩余次数。提前结束可在原观看窗口内继续播放。完播证明经账号服核验后，由角色所属运行服自动增加托管秒数。在线角色收到托管余额更新，离线角色下次入场可读取同一笔已入账结果。 [最终策划 §4.12](../最终策划案.md#412-商业化与托管时间角色独立双卡) · [托管页入口](../client/assets/scripts/app/GameRewardedAd.ts)

## 参数来源

| 内容 | 本轮取值 | 来源 |
| --- | --- | --- |
| 每次完播奖励 | 3600 秒 | 玩法工作簿 `game_entitlement_rules/26` 候选值 |
| 核验要求 | 可信渠道的唯一完整播放事件 | 玩法工作簿 `game_commercial_candidates/7` 已定 |
| 每日额度维度 | 账号、设备、IP | 玩法工作簿 `game_commercial_candidates/8` 已定 |
| 隔离日限量 | 账号 2 次、设备 2 次、IP 3 次 | 隔离装配样本 |
| 隔离观看与送达时间 | 180 秒观看窗口，另有 120 秒回调送达宽限 | 隔离装配样本 |

规则编译器固定工作簿、前置规则和隔离装配摘要。规则 30 的默认配置关闭激励视频。正式广告位、渠道验签方式和数字限量待确认。 [隔离规则投影](../tools/resources/prepare_rewarded_ad.py) · [隔离装配](../tools/resources/testdata/rewarded-ad-isolated.json)

## 核验与到账

- 账号服校验原账号、永久入口与角色。观看凭据固定原受益人、广告位、奖励秒数和时间窗口。同账号的角色共用每日额度，存在一笔在途观看时可查询其状态。 [观看请求](../server/internal/persistence/rewarded_ad_attempt.go) · [账号消息](../shared/proto/rewarded_ad.proto)
- 回调需由已装配的渠道适配器证明完播、原广告位、受益标记、唯一事件、实际完成时刻和可信设备与 IP。设备及 IP 只持久化摘要。额度按实际完成时刻对应的上海运营日核算，三类额度一起提交。共享 IP 触及上限只影响当前广告发放。 [渠道核验](../server/internal/rewardedad/verifier.go) · [回调与额度](../server/internal/persistence/rewarded_ad_callback.go)
- 游戏服按永久入口对应的当前运行服派送已核验事件。资产事务一起保存托管秒数、角色修订、原回执和审计，按原事件去重。领取免费时长的运营日状态和钱包继续沿各自的业务流水。余额超过 24 小时仍可累加广告时长。 [运行服派送](../server/internal/game/rewarded_ad_jobs.go) · [资产事务](../server/internal/persistence/rewarded_ad_delivery.go)
