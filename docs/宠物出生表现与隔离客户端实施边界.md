# 宠物出生表现与隔离客户端实施边界

日期：2026-10-29。状态：rule18限定验收通过；具体检查、真实构建与正常触屏范围见[阶段验收](宠物出生表现与隔离客户端阶段验收.json)。来源映射、组件检查、真实业务与硬件听感分别登记，不据此宣布完整1.80、三职业或P0完成。

## 规则与开放范围

主profile仅将rule_version从17推进到18，作为新增纯S2C消息的客户端版本边界。仍选择22项技能，不含17；原商店、初始赠书、材料关闭、187未知容量及legacy免费未训宠保持。独立召唤目录仍runtime_enabled=false、required_rule_version=17。护符包Count单位与售价未获用户答复，不从DuraMax或声音/美术索引猜值。

玩法数值继续只维护两本唯一Excel，本次只改玩法书开发profile的一处版本字段。素材帧映射属于资源元数据，由[来源契约](../资料索引/宠物出生表现来源契约.json)与锁定来源派生；不会再维护一套出生业务延迟。既有500ms召唤到期、2000ms普通走攻就绪、1000ms图像序列和原WAV时长分别有自己的含义，不合并为同一时钟。

## 真实出生与传输

Crystal的BoneFamiliar首次Spawned先广播Extra=false，再设置Summoned=true；后续GetInfo、健康重观和召回均不会重新排Appear。本作采用一次临时S2C `PetBorn`（30015）表达这一事实。只在fresh17真正安装成功后产生，Recall、legacy、到期失败、非当前World或未完成本连接SyncReady的出生不产生，也不积压给下一张票。

SyncReady必须真实成功进入原连接发送队列，随后以stamp锁定连接、绑定、角色、执行、完整World.Ref、完整Auth、scene及baseline；不能仅凭地图ID或执行epoch相同就沿用旧凭据。新生先发送包含精确身体的完整基线组；全部分片入队成功且附件、身体和状态序号仍匹配，才发送一次PetBorn。任一发送失败不回滚已经发生的材料提交或宠物业务，也不向下一连接重试显示事实。

事件包含scene、baseline、state sequence、handle、Life、身体definition、地图、原cast/skill、实际出生Unix毫秒、movement revision、方向、RoleKey和elapsed_ms。64位字段保持Go uint64及客户端Long/BigInt；movement revision为0合法。elapsed_ms来自实际出生到发送的服务端单调时钟，客户端仅再累计接收后的单调时间，不拿本机Date与服务器Unix相减。

## 客户端归属与表现

Session按连接、绑定、角色、scene、baseline和地图核验事件；同一附着最多保留一个待处理通知，按Life单调水位消费。需要完整基线达到事件序号，且现有活宠handle/Life/definition/地图/运动版本仍精确相同；事件不会创建身体。过期、死亡、位移、旧票、旧Life或附件失效只丢弃，不从Owned变化或首次baseline推断新生。同附着资源失效仅丢弃pending，保留已消费水位，避免换visual后重播。

手动旅行进入quiescing时，客户端ready虽暂时关闭，原附着仍可观察旧World已受理动作的Born并消费其表现，沿用既有Cast、Impact及Displacement的观察围栏；输入和经济操作的Ready/旅行门槛不放开。随后旅行Cancel保留原World时，已消费的同birth不得重播；真实新Entry仍清理旧scope及待处理通知，不能补播原世界历史出生。

新召17的40014未决日志精确保存sceneEpoch、inputSequence、skillId、direction、materialInstanceId、materialVersion、casterLife和operation共8字段，不含targetHandle/targetGrid；14/15仍要求原目标与地格的旧形状。不能为17补零坐标或夹带map/落点。客户端先完成字段校验和持久化，再调用GameConnection发送；校验或存储失败均禁发并退回本地命令推测。发送结果未知时保留原op、材料、Long生命/场景与版本重查，不创建替代操作。此次真实GUI发现的形状接线缺口已在这条客户端链修正，正常触屏结果仍须按新TS重新构建后另验。

原Mon4 2860–2869用于appear。真实Monster/78.Lib的Appear动作给出10帧、100ms间隔、方向stride0和加色；总长由count×interval派生。原WIL像素及偏移保留，所有方向使用同一序列。出现动作不推迟服务端AI、占格或AutoRecall；死亡及后续权威位移中止旧出场。头顶锚点继续取站立/行走身体，不随appear跳动。

原Magic1500–1509用于17起手，600ms及加色从来源施法身体动作与Effect默认混合推导。起手由CastAccepted驱动，fresh和Recall都可播放；它不证明500ms后真正出生。骨骷髅没有来源支持的附加落点效果，本轮不添加。

起手使用M65-0.wav，真正出生使用078-5.wav。两段原声分别约1136ms、1505ms，不裁剪为600ms或1000ms。WorldAssets入场预载并持有AudioClip；正常触屏在保存Safe根的TOUCH_END捕获阶段解锁，先于Button停止冒泡；全局input仅作未被UI认领触摸的fallback，不能依赖它收到普通按钮事件。同一解锁去重，current旧scope拒绝。实际音效由真正AudioSource播放，不使用DOM监听、QA私调解锁或禁autoplay参数。动画窗口只约束迟到声音是否仍可开始，成功播放后按原clip完整剩余时长结束。旧异步回调不能播放到替换后的声道；世界、生命或视图归属失效时停止并解绑，再释放引用。

保存Safe通过公开NODE_DESTROYED事件提前退休音频，顺序早于引擎清空根事件表及销毁子树；外层AppRoot.onDestroy可能晚于该子树。全局input始终按原callback/context主动退订；普通主动释放时，根监听按创建时同一root、callback、context及capture退订，根已进入公开销毁通知后则由引擎自行清空事件表，不再调用已毁根的off。Creator3.8.8的isValid(strict)只检查Destroyed与ToDestroy，不包含Destroying，因此另记根退休状态。排队ToDestroy但尚存活的AudioSource仍先stop并解绑clip，不重复destroy；实际已毁组件已由引擎onDestroy清理，不再触碰。迟到播放拒绝排队组件，旧实例再次释放不影响同Safe上新实例。真实换角GUI发现的销毁顺序缺口已修正并通过纯检查，仍须新TS实构后的正常换角验证，不能把前序GPU或播放成功当作整轮GUI通过。

## 独立真实触屏验证

独立工程位于本项目.work，除下述单项可再生Editor缓存外，逐字复制主工程资产、脚本、协议、meta、settings及保存布局；只将同一局部fixture通过既有public_gameplay白名单编译器生成的public写入独立工程。使用Creator3.8.8真实构建并冻结输入、输出摘要；允许在声明精确单项排除后的当前source全树、独立input全树，以及完整build全树和同一fixture编译public的SHA全部严格相等时复用这一真实构建，并记录原构建与本次GUI各自身份和范围。任一TS或其它受控输入变化必须重新构建，不能沿用旧包作为当前验收；复用不替换resources，不私注对象或伪造施法。
