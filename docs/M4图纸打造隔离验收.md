# M4 图纸打造隔离验收

隔离服的骷髅精灵胜利附件可以发放矿纹项链图纸。玩家在背包点击图纸，选择本次要投入的四块黑铁矿，查看报价后提交。候选成品为 20 级稀有项链，金币参考价 30,000 来自唯一玩法工作簿。四块黑铁采用策划中的稀有历史测算输入，首领固定图纸附件及成品身份只用于验收。正式配方和图纸掉率仍待补齐。 [策划 §4.25](../最终策划案.md#425-挖矿图纸打造与修理) · [隔离装配](../tools/resources/testdata/README.md)

每次打开时，使用绑定资源默认关闭。玩家完成两次确认后，当前界面才允许选择绑定图纸或矿石，并按绑定金币优先安排实际扣款。报价展示原图纸、每块矿石的纯度和绑态、金币分账、装备部位、等级、品质及最终绑定。图纸、任一矿石或实际扣款有绑定部分时，成功的原装备实例绑定。 [触屏操作](../client/assets/scripts/app/GameForge.ts) · [报价计划](../server/internal/persistence/forge_plan.go)

黑铁平均纯度决定实际成功率，平均达到 95 时直接显示 100%。成功和失败都扣除本次黑铁及报价金币，成功才消耗图纸并生成一件装备。成功后按工作簿的 15% 独立抽取初始幸运，触发时按候选等权选 1 至 3。原实例保存幸运值、有效耐久与绑定。初始幸运参与战斗、装备额外基础属性及后续幸运培养仍属长线养成范围。 [服务端计划与结果](../server/internal/persistence/forge_plan.go)

报价绑定原角色、会话、场景、运行服租约、资产版本和规则摘要。提交时重新比对实际材料及费用。过期、换场或原投入变化时刷新并重新确认。原操作编号、消耗和成功或失败的结果在同一个事务确认，结果已提交后可重连查回，随机结果不会重抽。 [报价与事务](../server/internal/persistence/forge_quote.go) · [协议](../shared/proto/forge.proto)
