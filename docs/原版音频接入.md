# 原版音频接入

2026-11-20。本机试玩从用户提供的 `传奇1.80客户端/Wav` 导入 52 份原字节 PCM WAV，合计 56,280,110 字节。上一阶段的 7 份原创音频及其合成脚本已从项目移除。来源、格式、字节数与 SHA-256 见[原版音频来源清单](../资料索引/原版音频来源.json)。

## 播放对应

- 登录播放 `Log-in-long2.wav`，选角播放 `main_theme.wav`。参考 Delphi 的 `Grobal2.pas` 选择 `Var_185`，`SoundUtil.pas` 定义两条曲目，`IntroScn.pas` 调用循环播放。
- 当前个人图和来源城镇共用原始野外音轨 `Field2.wav`。参考客户端的地图流程从服务端取得 `Music/<编号>.mp3`，本地参考中没有现有地图的对应专曲；共用野外曲是试玩配置。
- 普通按钮使用原 103 号音。角色按裸手、木剑和男女角色状态选择挥击、着体、受击及死亡声音。稻草人用原 470 组，变异骷髅用原 570 组的对应条目。每次附着的初始快照只建立观察基线。
- 技能独立映射施法、飞行、爆发与挥砍。现有 22 项主配置中 19 项可找到可用原音。基本剑术和精神力战法是被动项，野蛮冲撞未找到足以绑定的原播放事件。雷电术使用现存爆发声。隔离召唤使用的原施法与出生样本，分别与 `M17-1.wav`、`M17-3.wav` 逐字节相同。

## 本机导入

```powershell
./tools/dev.ps1 python3 -B tools/resources/import_original_audio.py
./tools/dev.ps1 python3 -B tools/resources/import_original_audio.py --check
```

原客户端在其它路径时可加 `--source-dir` 指向其 `Wav` 目录。工程使用本机导入的 WAV 和固定 UUID 元数据，版本库保存映射、导入工具与来源摘要。未安装原 WAV 的开发副本可以静音运行。Web Mobile 的音频在首次触屏后播放，舞台销毁、回到其它场景或进入后台时停止对应音效。
