# 手动技能与自动施法

技能面板显示当前职业技能。角色未学时显示学习等级或缺少技能书。达到等级并拥有对应技能书时，选择技能并点「学习」确认。未学习的技能不会占用底栏快捷位。

## 手动使用

- 点技能行只选择技能，点「详情」查看条件。已学主动技能可直接施放或设为底栏手动快捷。方向或范围技能按战斗画面提示选择落点。点怪物或活宠选定目标，点右侧「目标」单独看资料。
- 刺杀、半月学会后可从快捷位或技能页开关，以服务端确认显示结果。开启后随普攻出招，刺杀需要正前方第二格有活怪。半月符合出招条件时仍优先于刺杀。烈火沿用充能再攻击，被动技能沿用普攻触发。

## 自动施法

- 技能面板的「自动施法」控制自动施放。对已学且支持自动的技能，可以单独选「自动使用」或「仅手动」。右侧「自动」仍控制在线自动战斗，单独改技能偏好不会改变战斗开关和怪物数量。
- 自动战斗和离线托管都从角色当前位置定点打怪。射程内没有可攻击的目标时原地等待。玩家仍可推摇杆或点地换点，移动结束后就在新位置继续定点战斗。宠物沿自身规则跟随和攻击。
- 自动战斗会锁定当前活怪。目标一时出射程或被挡住时，角色会继续等这只怪。目标死亡后再选择下一只可攻击的活怪。自动开着且当前没有目标时，可以点一只活怪指定首个目标。范围技能仍可波及附近怪物。
- 服务端沿既有技能优先级与条件选招。火球寻找射程和视线内的活怪，治愈只选需要治疗且尚无治疗队列的自己或活宠。没有适用技能时尝试原地普攻，施法仍需要足够魔法和冷却结束。
- 偏好按角色保存在本机浏览器，入场时同步。在线战斗与同现场离线托管使用已确认的同一设置。首次使用沿用游戏的默认自动策略。

怪物倒下时隐藏头顶名字和血条，继续播放死亡动画并显示尸体。怪物重生后恢复头顶显示，新生命重新参与选怪。

## 伤害飘字

攻击命中时，在受击实体头顶显示本次实际扣除的生命值，数字上浮并淡出。玩家、宠物和怪物的伤害走同一条结算事件。致死一击以实际剩余生命计算。治疗入队、零伤害和抵抗没有伤害数字。

客户端按当前场景、受击实体生命代次与结算序号核验。同目标的连续数字错位显示，同屏最多十条。数字使用项目字形及独立的 Creator 预制体。

## 验收

- 锁定 Go 全包、三项随机库真实 MongoDB 与 WebSocket 联调、510 项客户端测试、16 项场景测试和 152 项配置测试通过。离线实际扣时后健康重连保留角色位置及移动修订，紧凑城镇往返仍可用。
- Creator 3.8.8 Web Mobile 实构通过。隔离的 Chromium 触屏在同一客户端和服务端二进制上验证三职业。战士定点触发二格刺杀，手动点地及摇杆换点后保持新脚点。法师和道士用职业初始书正常学习，验证关闭自动时可手动施法，重进保留总开关和单技能设置，重新启用后自动火球命中、治愈入队并回血。测试角色入场前预置等级，战士预置已学刺杀。道士使用试玩已有的多怪设置取得实际受伤状态。
- 按用户授权重启游戏服务。原试玩入口返回新客户端，项目专属 MongoDB 和网页代理继续运行。

2026-11-20 补验自动锁怪与怪物头顶显示。隔离 Chromium 角色正常建角并使用职业初始技能书，入场前仅补至测试等级。四怪场景中，法师连续施法锁住同一生命，实际点选另一只活怪也维持原目标，原目标死亡后才换怪。尸体节点保持可见、名字和血条隐藏，同槽重生后恢复。104 份权威快照的角色位置和移动修订一致。

2026-11-20 验收伤害飘字。518 项客户端测试、16 项场景测试、Creator TypeScript 严格检查和 Go 全包测试通过。隔离 Chromium 中，职业初始火球命中与怪物反击的数字均对应真实扣血，上浮、淡出和回收正常。同一结算的即时重复与过期重复均未再产生数字。同一角色的并发受击显示两条错开的数字。宠物命中与宠物受击的权威伤害回包通过独立 MongoDB 与 WebSocket 联调。
