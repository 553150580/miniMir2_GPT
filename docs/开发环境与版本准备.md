## 例行检查

```bash
./tools/dev python3 tools/environment/check.py --strict
./tools/dev go version
./tools/dev protoc --version
./tools/dev protoc-gen-go --version
./tools/dev python3 --version
./tools/dev uv --version
./tools/dev go mod verify
./tools/dev go run ./cmd/toolchain-smoke
```

环境检查写入`docs/开发环境检查.json`，逐项检查实际版本、安装/依赖锁、生成输出摘要和当前专用Mongo运行状态。Mongo状态先由专属控制器确认进程/转发归属，再只读查询`hello`、`buildInfo`和单成员配置；不启停服务、不初始化数据库、不访问玩家集合、不重跑写事务。事务能力采用已保存且对应当前run-id的验证证据。

`--strict`在工具或开发数据库未就绪时返回2。只查工具可用`--skip-database`，此时不会把未检查的数据库标成ready；`--report .work/环境检查.json`可保存独立检查报告。数据库被主动停止后，`toolchain_ready`可仍为true，`development_database_ready/development_ready`应为false；不能把一次历史验证当成当前服务仍在运行。

## 专用开发数据库

连接：`mongodb://127.0.0.1:27118/?replicaSet=minimirDev&directConnection=true`。该URI仅用于本机隔离开发环境，不含凭据，不可作为生产配置。guest Mongo只监听`127.0.0.1:27017`，Lima转发只绑定宿主`127.0.0.1:27118`。

```bash
./tools/dev python3 tools/environment/mongodb_dev.py status
./tools/dev python3 tools/environment/mongodb_dev.py start
./tools/dev python3 tools/environment/mongodb_dev.py stop
./tools/dev python3 tools/environment/lima_dev.py status
./tools/dev python3 tools/environment/lima_dev.py stop
```

Mongo控制器只管理本项目二进制、安装标记、独立dbpath、PID/run-id和回环端口。`start`复用已运行实例并验证单节点事务；`stop`只关闭本项目Mongo，不停止VM。需要释放VM内存时先停止Mongo，再停止VM。两者均不注册自动开机。

VM为2CPU、3GiB内存和20GiB稀疏磁盘，不挂载宿主HOME或原始参考资料。guest用户目录为`/home/srf.guest`，Mongo位于其独立用户目录。宿主Python工具环境与PyMongo驱动venv相互独立；Mongo控制器自动选择专用PyMongo4.19.0环境。
