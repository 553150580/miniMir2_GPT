## 生成与校验

以下命令在 Windows 试玩机从项目根目录运行。其它机器将 `--source-root` 指向同摘要的本机原客户端目录，其中应有 `Map` 和 `Data` 两个子目录。MYF `0.map` 读取项目内只读参考副本 `资料参考/myf/Mir200/Map/0.map`。

```powershell
.\tools\dev.ps1 python -B tools/resources/prepare_regional_map_art.py --source-root 'D:\123DownLoad\Miro2_1.80\传奇1.80客户端'
.\tools\dev.ps1 python -B tools/resources/prepare_regional_map_art.py --source-root 'D:\123DownLoad\Miro2_1.80\传奇1.80客户端' --check
```

输出在 `client/assets/resources/development/map-styles/`。清单记录原图、所用瓦片、采样原点及产物 SHA-256。PNG 和对应 Creator 资源标识使用内容版本，当前已有地图资源可继续供历史客户端引用。生成物保留在本机开发试玩，版本库记录生成方式与来源。生成及逐项复验均通过，六张地表的散列各异。 [生成工具](../tools/resources/prepare_regional_map_art.py) · [原比奇地图来源](../资料索引/来源城镇地图补充.json)

## 切图耗时

地图准备阶段并行加载公共清单与预制体。紧凑地图按目的地、可见职业与实体分组加载原帧图集，逐帧校验无损像素。客户端至多保留一张最近离开的普通图或轻量地图 45 秒，纹理预算上限 64 MiB。新地图仍需完成服务端的旅行计划、原场景收束、首基线和视口确认后才能操作。世界首领继续使用独立图集。 [地图素材生命周期](../client/assets/scripts/app/WorldAssets.ts) · [切图图集](../tools/resources/build_map_travel_atlas.py)

两份实际 Web Mobile 包在同机 Chromium 模拟触屏，禁用 HTTP 缓存，依次由林间战场前往五个目标再返回。新旧测试统一使用隔离角色生命值，避免旅途中被怪物击杀影响时间。计时从点击目标到场景可操作，包括线路确认与客户端首视口。下表为毫秒。 [触屏试验台](../tools/server/verify_map_travel.py)

| 目的地 | 旧版首次去程 | 新版首次去程 | 旧版返回 | 新版返回 |
| --- | ---: | ---: | ---: | ---: |
| 银杏山谷 | 14,167 | 795 | 3,698 | 81 |
| 边界村 | 13,992 | 560 | 3,802 | 78 |
| 比奇城 | 14,291 | 569 | 3,932 | 81 |
| 谷地南坡 | 6,191 | 449 | 5,032 | 39 |

五个去程合计资源请求从 14,083 次降至 122 次，五次原路返回从 1,356 次降至 0 次。新版去程从收到旅行计划到提交的中位数是 493 毫秒，旧版是 13,913 毫秒。浏览器核对了六张不同的已挂载 SpriteFrame，三城 NPC 分别为 6、6、9 位，普通图无建筑、无阻挡，五次返回均恢复正确地表。具体时间来自该机的同条件样本。 [浏览器计时代码](../tools/client/map_travel_benchmark.cjs)

个人首领专项使用同一套隔离角色条件和禁缓存浏览器。点击入场至场景确认由 6.30 秒降至 0.66 秒，击杀返回由 6.63 秒降至 0.44 秒。新版返回复用原地图素材，资源请求为零，待领、断线和领取流程也通过。世界首领的战士、道士首次入场分别为 1.38 秒和 1.39 秒。双端均在实际入场后加载原有 9 页图集，跨职业施法、宠物、重连和活动自动开闭均通过。
