# 客户端

本目录是Creator3.8.8工程，保存Boot/Login/RoleSelect/Game四个scene及六个prefab，当前为rule15、22项开发候选技能（含瞬息移动21）。完整来源城镇以目录2按原生48×32矩形格和视口分块加载；个人地图1继续17×17菱形。来源小地图在保存槽内等比显示，动态地图对象实例化保存的MapProp；固定布局不由生成器覆盖。

当前宠物驻留与替换表现基础通过352项JS（336应用/UI、16场景）及122.07秒Windows Creator实构，10份保存布局保持。同handle换definition/profile重建正确动画、头顶及层数；同Life保留位移水位和附体时钟，新Life及旧节点触屏隔离。此替换分支由真实TS受控Cocos组件用例验收，不冒称正常触屏已召唤神兽。当前道士健康城镇/绑定7项0错误0警告，通用UI6项保留1条方向警告。21完整购学/跨同图施放沿前阶段限定验收及本轮真实全包回归；17、护符、训练、独立尸体及宠物管理面板仍待接入，原免费开发宠物保留。见[宠物基础验收](../docs/职业宠物驻留与表现基础阶段验收.json)及[实施中边界](../docs/职业宠物生命周期与召唤实施边界.md)。

开发前先读 [客户端界面约定](AGENTS.md) 和 [场景管理与加载器](docs/场景管理与加载器.md)。固定布局、EditBox默认组件树、PopupView分层返回、触屏输入与导航状态保持均按约定逐项验收。

主界面采用用户2026-10-26上传的[布局参考图](../UI参考图/用户确认/主界面UI布局参考.png)，分区、固定布局和适配规则见[主界面布局基准](docs/主界面布局基准.md)。上阶段保存顶部128、底部344的HUD；同宽720下由1280加高至1600时，仅地图视口从808增至1128，控件、文字与图标不随之拉高。

上阶段制作30张1.80来源原像素UI图，接入职业头像、四钱包详情、小地图与真实坐标、药品数量、血蓝与经验、常用功能菜单。GameHUD负责数据绑定，GameMessages负责当前会话的真实系统记录；消息支持折叠两条、展开搜索和复用List，内置EditBox用于搜索，尚无聊天发送或世界聊天服务。历史浏览器与多尺寸证据见[主界面阶段验收](../docs/主界面阶段验收.json)。

既有红蓝快捷入口已接入手动用药：资源未满时直接提交，满资源时使用PopupView确认仍会消费；按当前库存顺序选择原药品实例，确认后仍校验原角色、场景、实例和版本。服务端权威扣1后分跳恢复，客户端根据真实库存与HP/MP更新显示。没有自动喝药；当前16项技能以候选范围开放，其余技能、完整职业升级范围、BOSS和任务继续保留未完成状态，具体来源与调度边界见[药品与技能实施边界](../docs/药品与技能实施边界.md)。

技能面板与条目模板保存在Game.scene，GameSkills绑定已有节点，SkillModel只做意图与目标预检；服务端决定学习、MP、命中与永久结果。当前16项为火球1、治愈2、基本剑术3、精神力4、大火球5、攻杀7、地狱火9、疾光10、雷电11、刺杀12、爆裂23、地狱雷光24、半月25、烈火26、群疗29、冰咆哮33，支持0–3阶材料升级，随机练功关闭。范围中心只检边界与射程，阻挡中心不整次拒绝；服务端到期逐目标筛有效格。AttackAccepted与CombatImpact分别表达受理和实际结果，客户端不按视觉范围扣血。

本阶段刺杀/半月复用原Use占位并追加保存的内置Toggle，与Use互斥，代码仅绑定及无通知恢复服务端勾选；烈火用充能入口。模式由scene、player life和Long revision隔离，同连接成功复活同步递增life和模式修订以恢复操作，健康重连不补播旧刀光。方向瞄准复用原提示、取消和落点节点，面板、瞄准、后台及尺寸变化不清地面导航，只有摇杆输入释放。

地狱火所有rank固定正前单线4格是用户审定本作例外，不采用源rank3左右射线。首格500ms、后格实际处理时钟+100ms，30012 CastStep收到后才播对应格；原客户端50ms视觉排程不作为业务时序，也不预排未来格。刀光随已受理的那次身体帧，疾光梁固定原施放点；所有贴图保留原尺寸和偏移，不按范围拉伸。实现边界见[战士攻击模式与方向技能](../docs/战士攻击模式与方向技能实施边界.md)。

在本目录执行：

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run protobuf:generate
npm run protobuf:verify
```

`protobufjs-cli@2.7.1`安装在用户级工具目录`~/.local/share/minimir-toolchain/node-tools/`，由项目工具调用。`MINIMIR_NODE_TOOLS`可显式指定该目录。客户端使用自己的`node_modules`解析运行依赖，验证过程不借用外部CLI的`NODE_PATH`。

64位协议字段使用`Long`，从十进制字符串或精确高低32位构造；禁止经不安全的JavaScript Number转换。编解码边界检查说明见生成目录内README，安装与验证证据见`../conf/toolchain/node-tools.lock.json`和`client-pb-verification.json`。

从Creator3.8.8打开本目录可编辑已保存的场景和预制体。固定UI层级不由运行时脚本重新创建，生成工具不得覆盖布局；`AGENTS.md`始终是本目录的当前约定。

在根目录执行`make client-scene-test`、`make client-test`、`make client-build`分别检查加载器、UI/应用与真实构建。当前协议54个PB数据消息、44个消息号、29个错误码、89个Long字段及288个边界案例。Creator3.8.8 Web Mobile本阶段真实构建314.29秒、exit36，源码稳定，7份scene/prefab构建前后保持；最终自动、服务端修复后全包race和浏览器结果以阶段报告为准，不在收尾中预填通过数量。上一范围技能阶段153项JS/23项Python/96条race/116.84秒，获取升级d1207bc的134项JS/20项Python/64条race/139.33秒，以及首组421ce1c的118/54/144.12均保留历史范围。
