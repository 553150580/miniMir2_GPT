# 客户端开发约定

本文件记录用户于2026-10-26直接确认的客户端规则，适用于本目录的代码、编辑器资产及相关生成工具。与根目录约定共同执行；客户端界面和美术来源以这里的用户最新约定为准。

## 客户端界面约定

- 客户端美术资源参考传奇1.80客户端；
- Creator 版本为 3.8.8，文本使用 UTF-8，注释和文档使用中文。
- 所有固定场景、UI层级、按钮、输入框、面板及列表条目模板必须保存为 Creator 可编辑的 .scene/.prefab，禁止运行时代码生成固定布局；代码只绑定引用、更新数据/文字/状态和实例化动态条目。工具不得覆盖已保存的场景或预制体布局。
- UIMgr 管理普通弹窗；独立 PopupView 管理其上的详情、确认和帮助。两层分别返回，关闭顶层不得销毁下层或清除滚动位置。所有弹窗不放单独关闭按钮，统一点击半透明背景关闭或返回。
- Creator 已提供的界面功能优先使用内置组件。
- 所有输入框保存为场景或预制体中的内置 `cc.EditBox`，沿用 Creator 默认 EditBox 的组件树；不能恢复旧的运行时 `edit` 造节点方式。
- 输入文本、占位、密码遮罩、焦点和键盘处理交给 EditBox；禁止创建第二套叠加标签或自行操作 DOM 输入框。
- 面板用 Sprite，按钮用 Button，开关用 Toggle，血条用 ProgressBar；长列表由自定义 List 复用可视节点，滚动和裁剪仍使用内置 ScrollView、Mask。
- 屏幕边缘停靠、居中和拉伸使用 Widget；交互区域使用 SafeArea。默认按窗口变化对齐，避免逐帧重算。
- 客户端发布为手机触屏模式，不需要监听电脑键盘；
- 屏幕变化时保持 UI、字体和图标的宽高比，只允许容器通过 Widget 调整可用空间；禁止把固定像素画布用 CSS 非等比铺满窗口。
- 宽屏增加地图视口宽度，顶部、底部、两侧 UI 保持 Widget 停靠，控件、文字、图标等比显示。所有Label字体大小最小为24；默认构建 Web Mobile。
- 用户补充：屏幕高度增加时保持UI布局、控件尺寸和顶部/底部停靠关系不变，增加的可用高度全部给战斗地图视口；通过扩大可见范围显示更多地图，不能拉高地图、角色、字体或UI，也不能随之加高聊天等固定面板。逻辑地图格数不随屏幕尺寸改变。
- 参考`D:\123DownLoad\GoMir2\client`，客户端要有场景管理器，弹窗由 UIMgr 统一管理，自定义List组件（高性能无限列表，支持自定义列表项）、Tab组件、ViewStack组件，按职责拆分。
- 交互以 Cocos 触摸事件和内置 Button 为入口；移动支持八方向摇杆及轻触地面寻路，不依赖键盘。
- 面板、聊天、点击实体和后台切换不能清除地面导航目标；失焦/后台/尺寸变化只释放摇杆输入。退出游戏或玩家主动接管方向才终止相应导航。
- EditBox 的文本子节点位置由输入组件管理，不额外挂 Widget；地图实体位置由游戏坐标管理，不使用 Widget。
- Graphics 仅用于地图、实体占位图形及确实没有对应 UI 组件的游戏绘制。

## 场景管理加载器

客户端必须有独立的场景管理加载器，按 `SceneManager`、`SceneLoader` 和Creator加载桥接的职责组织，见 `docs/场景管理与加载器.md`。必须覆盖预加载、真实加载进度、场景切换、失败恢复、防重复/过期回调和明确的资源归属。

加载界面也是固定布局，必须使用已保存的.scene/.prefab及内置组件。服务脚本可接收编辑器绑定引用和更新加载状态，不能创建一套替代的加载界面，也不能清除导航目标或代替网络模块确认入场。
