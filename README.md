## 本地检查

在本项目目录执行，`tools/dev`选择已经安装并锁定的较新工具。Go命令自动以server为工作目录：

```bash
make environment
make check
make test
make protocol
make preview
make client-test
make client-build
make server-integration-test
make development-resources-check
```

启动本地开发服务使用`make dev-start`，查看与停止使用`make dev-status`、`make dev-stop`。客户端同源入口为`http://127.0.0.1:18080`，account/game/gm分别监听18100/18101/18102；开发工具管理进程，数据库由独立Mongo开发环境管理。

`--check` 默认检查数据结构。预览配置中的 `runtime_ready=false` 表示还存在待核验内容或业务验收。正式门禁单独执行：

```bash
make release-check
```

首开发闭环和主界面阶段的历史验收已通过，`development_loop_ready=true`；[主界面阶段验收](docs/主界面阶段验收.json)保留对应构建档案。药品阶段本机验收已通过，见[药品阶段验收](docs/药品阶段验收.json)。当前技能阶段实现与自动检查已通过，浏览器首组关键路径已核对，首次状态变化观察仍保留追踪。正式门禁仍列出492项阻断并拒绝发布，`runtime_ready=false`、`production_ready=false`；完整技能、完整聊天、完整P0与手机真机尚未完成。

## 资料与配置边界

- 上级参考目录只读检索，转换和开发产物写在本项目中；不运行来源程序或部署脚本。
- 参考工程的技能、掉落和数值是候选来源，目标1.80归属逐条核验。
- 初次提取记录位于 `config/catalog/fragments/`，后续参数只在Excel中维护。`config/schema/catalog.json` 负责字段、导出目标和发布门槛，不是第二份数值表。
- 客户端只接收公共/展示字段；服务端控制字段、来源和历史经济样本不下发。
- 代码、注释和说明使用UTF-8；运营日界为Asia/Shanghai；金额按最终策划的整数精度表示。
