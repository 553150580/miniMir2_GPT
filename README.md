## 资料与配置边界

- 上级参考目录只读检索，转换和开发产物写在本项目中；不运行来源程序或部署脚本。
- 参考工程的技能、掉落和数值是候选来源，目标1.80归属逐条核验。

- 客户端只接收公共/展示字段；服务端控制字段、来源和历史经济样本不下发。
- 代码、注释和说明使用UTF-8；运营日界为Asia/Shanghai；金额按最终策划的整数精度表示。
